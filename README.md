# mehr alemi

Astro tabanlı statik edebiyat sitesi.

## güncel yapı
- ana sayfa: şiir / düz yazı filtreli görsel arşiv
- ilk 5 içerik + her tıklamada 5 içerik daha
- görseller scroll ile siyah-beyazdan renge geçer
- hakkında sayfası
- Pages CMS içerik modeli
- GitHub Pages deploy workflow
- eskitilmiş / buruşuk kâğıt yüzey
- profil görseli header, hakkında sayfası, favicon ve sosyal paylaşım görseline entegre edilmiştir

## profil görseli dosyaları
- `public/media/mehr-alemi-profile.jpg`
- `public/media/mehr-alemi-profile-thumb.webp`
- `public/media/mehr-alemi-icon-256.png`
