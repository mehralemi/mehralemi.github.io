# mehr alemi — v64

Bu sürüm v63 tam site paketinin güncellenmiş halidir.

## Değişiklikler
- kırmızı ve yeşil CTA / aktif filtrelerde parlak beyaz metin kaldırıldı
- yerlerine sıcak, kırık kâğıt tonlarında okunaklı metin renkleri getirildi
- `yazılar` / `hakkında` hover metni artık beyaza dönmüyor
- `hepsi / şiir / düz yazı` aktif filtre yazıları daha sakin tonlarda
- ana sayfa özet metinleri daha koyu ve net
- yazı ve hakkında sayfalarındaki uzun metinler daha okunaklı
- link, blockquote ve yardımcı metin kontrastları iyileştirildi
- buruşuk kâğıt texture katmanı bütün gerçek içeriğin arkasına alındı
- texture artık görsellerin üzerine binmiyor
